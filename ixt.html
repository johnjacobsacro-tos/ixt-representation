02 • QUICK REVIEW

Let's Review: Loops and Arrays

Before moving to our new lesson, let's remember two JavaScript concepts.

01

Loops

Loops repeat a block of code while a condition is true or for a specific number of times.

for (let i = 1; i <= 3; i++) {
  console.log(i);
}

Output: 1, 2, 3

02

Arrays

An array stores multiple values in a single variable. Each item has an index.

let fruits = [ "Apple","Mango","Banana" ];

  console.log(fruits [0]);

Example: fruits[0] is "Apple".

Remember: Loops repeat instructions, while arrays organize multiple values.

What is a JavaScript Object?

Objects help us group information that belongs together instead of storing everything separately.

03 • TOPIC 1

Properties and Values

Every property in an object has a corresponding value.

A

Property

A property is the name or label that describes a piece of information in an object.

name

It tells us what information is being stored.

B

Value

A value is the actual information assigned to a property.

"Alex"

It tells us the information stored under that property.

EXAMPLE

let student = {
  name: "Alex",
  age: 17
};

name and age are properties. "Alex" and 17 are their values.

03 • TOPIC 1

How to Access Object Values

JavaScript provides two common ways to get information from an object.

Dot Notation

student.name

Uses a dot followed by the property name.

Result: "Alex"

Bracket Notation

student["name"]

Uses square brackets and the property name inside quotation marks.

Result: "Alex"
Both methods can access the value of a property in an object.

04 • TOPIC 2

What is the Document Object Model?

The DOM is a programming interface that allows JavaScript to access and change the content and structure of a webpage.

document
html
head
body
h1
p
button

Think of it as a family tree.

The DOM organizes the elements of an HTML document into a tree-like structure.

JavaScript can use this structure to find elements and update them.

04 • TOPIC 2

Understanding DOM Nodes

A node is an individual part of the DOM tree.

E

Element Node

Represents HTML elements such as <h1>, <p>, and <div>.

T

Text Node

Contains the text written inside an HTML element.

A

Attribute Node

Represents attributes of an element, such as id or class.

C

Comment Node

Represents comments written in an HTML document.

These nodes help JavaScript understand and work with different parts of a webpage.

04 • TOPIC 2

How JavaScript Uses the DOM

JavaScript can select an HTML element and change its content.

HTML

  Hello, World!
</h2>

JAVASCRIPT
